
# 📘 Atividade: Jogo da Forca em Python

## 🎯 Objetivo

Construa uma versão de terminal do jogo da Forca para praticar manipulação de strings, listas, entrada de dados, seleção aleatória, loops e condicionais.

## 📝 Tarefas

### 🛠️ Preparação da Partida

#### Descrição

Prepare uma lista de palavras e escolha uma delas aleatoriamente para iniciar cada partida. Mostre a palavra oculta com traços ou espaços reservados e defina o número de tentativas disponíveis.

#### Requisitos

O programa concluído deve:

- Manter uma lista predefinida com pelo menos cinco palavras.
- Escolher uma palavra aleatoriamente no início da partida.
- Exibir um espaço reservado para cada letra da palavra escolhida.
- Definir e informar ao jogador quantas tentativas incorretas são permitidas.

### 🛠️ Rodada de Palpites e Resultado

#### Descrição

Implemente o ciclo principal do jogo: receba palpites de letras, atualize a palavra exibida e encerre a partida quando o jogador vencer ou ficar sem tentativas.

#### Requisitos

O programa concluído deve:

- Solicitar um palpite de letra a cada rodada e comparar sem diferenciar letras maiúsculas de minúsculas.
- Revelar na palavra exibida todas as posições que correspondem a um palpite correto.
- Reduzir as tentativas restantes quando o palpite não estiver na palavra.
- Continuar até que todas as letras sejam reveladas ou as tentativas acabem.
- Informar se o jogador venceu ou perdeu; em caso de derrota, revelar a palavra escolhida.
